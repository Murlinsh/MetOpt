# Как работают методы оптимизации

Этот документ объясняет идею, шаги и особенности каждого метода, реализованного
в приложении. Он открывается из верхней панели кнопкой «Алгоритмы», а также
кнопкой «Как работает метод?» на странице выбора метода.

Во всех методах решается задача поиска минимума функции двух переменных:

```text
f(x, y) → min
```

Основные обозначения:

- `x = (x, y)` — текущая точка;
- `f(x)` — значение функции в точке;
- `∇f(x)` — градиент, вектор частных производных;
- `H(x)` — матрица Гессе, матрица вторых производных;
- `epsilon` — требуемая точность;
- `d` — направление шага;
- `alpha` — величина шага.

Общий критерий остановки для большинства методов — малость нормы градиента
`‖∇f(x)‖ ≤ epsilon` или малость изменения координат за итерацию.

---

<a id="hooke_jeeves"></a>
## 1. Метод Хука-Дживса

**Группа:** методы без производных.

**Идея.** Метод последовательно исследует окрестность текущей точки по каждой
координате, а затем делает «шаг по образцу» в направлении, которое оказалось
удачным. Производные не нужны — только значения функции.

**Шаги:**

1. Задать начальную точку `x` и начальный шаг `h` по каждой координате.
2. Исследующий поиск: пробовать шаги `+h` и `−h` по `x`, затем по `y`.
   Если значение функции уменьшилось — перейти в новую точку.
3. Если исследующий поиск дал улучшение, выполнить поиск по образцу:
   `x_pattern = 2·x_new − x_old`, затем снова исследующий поиск.
4. Если улучшения нет, уменьшить шаг: `h = alpha·h`, где `0 < alpha < 1`.
5. Остановиться, когда `max(|h_x|, |h_y|) ≤ epsilon`.

**Параметры приложения:**

- `h` — начальный шаг;
- `alpha` — коэффициент уменьшения шага.

**Особенности.** Метод прост и не требует гладкости функции, но может делать
много вычислений и чувствителен к выбору начального шага.

---

<a id="nelder_mead"></a>
## 2. Метод Нелдера-Мида

**Группа:** методы без производных.

**Идея.** В пространстве переменных строится симплекс — треугольник для двух
переменных. На каждой итерации худшая вершина симплекса отражается, растягивается
или сжимается, чтобы симплекс «полз» к минимуму.

**Шаги:**

1. Построить начальный симплекс из трёх точек: `P0 = x0`, `P1 = x0 + step·e_x`,
   `P2 = x0 + step·e_y`.
2. Упорядочить вершины по значению функции: `f(P_best) ≤ f(P_good) ≤ f(P_worst)`.
3. Найти центр тяжести лучших вершин.
4. Выполнить отражение худшей вершины с коэффициентом `alpha`.
5. В зависимости от результата — растяжение (`gamma`) или сжатие (`beta`).
6. Если симплекс слишком вытянут, выполнить глобальное сжатие.
7. Остановиться, когда разброс значений функции в вершинах мал.

**Параметры приложения:**

- `step` — начальный размер симплекса;
- `alpha` — коэффициент отражения (обычно 1.0);
- `beta` — коэффициент сжатия (обычно 0.5);
- `gamma` — коэффициент растяжения (обычно 2.0).

**Особенности.** Метод надёжен для гладких и негладких функций, но не использует
информацию о производных и может медленно работать в оврагах.

<a id="ravine"></a>
## 3. Метод оврагов (Гельфанда-Цетлина)

**Группа:** методы без производных.

**Идея.** Если функция образует узкий и изогнутый овраг, обычный спуск начинает
«метаться» между стенками. Метод оврагов сначала спускается к дну оврага, а затем
делает осторожные шаги вдоль дна, периодически подстраиваясь под его изгиб.

**Шаги:**

1. Из начальной точки выполнить внутренний спуск к дну оврага (в реализации —
   градиентный спуск с дробным шагом, но сам внешний метод производные не
   требует).
2. Сделать внешний шаг `h` вдоль выбранной оси.
3. Снова спуститься к дну оврага.
4. Если значение функции улучшилось — продолжить в том же направлении.
5. Если улучшения нет — уменьшить шаг и сменить ось.
6. Остановиться, когда `h ≤ epsilon`.

**Параметры приложения:**

- `h` — внешний шаг поперёк/вдоль оврага;
- `inner_eps` — точность внутреннего спуска к дну оврага.

**Особенности.** Метод хорошо работает на овражных функциях, но внутренний спуск
требует дополнительных вычислений.

---

<a id="coordinate_descent"></a>
## 4. Покоординатный спуск

**Группа:** методы без производных.

**Идея.** На каждой итерации функция минимизируется по одной координате при
фиксированной второй, затем по другой. Для двух переменных это выглядит так:
сначала ищем минимум вдоль оси `x`, потом вдоль оси `y`, и повторяем цикл.

**Шаги:**

1. Задать начальную точку `x` и точность `epsilon`.
2. Зафиксировать `y` и найти минимум функции по `x` на отрезке, содержащем
   текущую точку.
3. Зафиксировать `x` и найти минимум по `y`.
4. Повторять цикл, пока смещение точки за итерацию не станет меньше `epsilon`.

Для одномерного поиска используется метод золотого сечения: он не требует
производных и последовательно сужает отрезок, на котором находится минимум.
Начальный отрезок автоматически расширяется, если минимум лежит дальше текущей
окрестности.

**Параметры приложения:** дополнительных параметров нет, используется общая
точность `epsilon`.

**Особенности.** Метод очень прост, не требует производных и хорошо работает для
функций, у которых переменные слабо связаны. Для сильно повёрнутых оврагов он
может сходиться медленнее, чем градиентные методы.

<a id="steepest"></a>
## 5. Наискорейший градиентный спуск

**Группа:** градиентные методы.

**Идея.** В каждой точке двигаться в направлении, противоположном градиенту:
именно это направление является направлением наискорейшего локального убывания.

**Шаги:**

1. Вычислить градиент `g = ∇f(x)`.
2. Если `‖g‖ ≤ epsilon` — остановиться.
3. Задать направление `d = −g`.
4. Подобрать шаг `alpha` по направлению `d` (дробный шаг с условием Армихо).
5. Перейти в точку `x_new = x + alpha·d`.
6. Повторять.

**Параметры приложения:** дополнительных параметров нет.

**Особенности.** Метод надёжен и прост, но в оврагах может сходиться медленно:
направление градиента всё время меняется, и траектория «зигзагует».

<a id="conjugate"></a>
## 6. Метод сопряжённых градиентов (Флетчер-Ривс)

**Группа:** градиентные методы.

**Идея.** Вместо того чтобы каждый раз идти строго против градиента, метод
запоминает предыдущее направление и строит новое сопряжённое направление. Для
квадратичных функций это позволяет найти минимум за число шагов, близкое к
размерности задачи.

**Шаги:**

1. Вычислить `g = ∇f(x)` и задать `d = −g`.
2. Если `‖g‖ ≤ epsilon` — остановиться.
3. Найти шаг `alpha` вдоль `d` и перейти в новую точку.
4. Вычислить новый градиент `g_new`.
5. Вычислить коэффициент `beta = (g_new·g_new) / (g·g)`.
6. Построить новое направление `d_new = −g_new + beta·d`.
7. Повторять.

**Параметры приложения:** дополнительных параметров нет.

**Особенности.** Обычно сходится быстрее наискорейшего спуска, особенно на
квадратичных функциях. Для негладких функций и неудачных шагов направление может
«портиться», поэтому шаг подбирается с проверкой убывания.

---

<a id="sgd"></a>
## 7. Стохастический градиентный спуск (SGD)

**Группа:** градиентные методы.

**Идея.** Если функция представима как сумма слагаемых, можно на каждой итерации
использовать градиент не всей суммы, а одного случайно выбранного слагаемого.
Это дешевле по вычислениям, но вносит случайность.

**Шаги:**

1. Разложить функцию на сумму слагаемых.
2. На каждой итерации случайно выбрать одно слагаемое.
3. Вычислить градиент выбранного слагаемого и умножить его на число слагаемых
   (чтобы оценка была несмещённой).
4. Сделать шаг с уменьшающейся скоростью обучения
   `alpha_k = alpha0 / (1 + c·k)`.
5. Проверять сходимость по полному градиенту, а не по градиенту одного
   слагаемого.
6. Если за отведённое число итераций сходимость не достигнута, вернуть лучшую
   найденную точку и сообщить об этом.

**Параметры приложения:**

- `alpha0` — начальная скорость обучения;
- `c` — скорость затухания;
- `normalize` — нормализовать ли приближение градиента перед шагом.

**Особенности.** SGD — стохастический метод: даже при близости к минимуму
отдельные шаги могут уводить точку в сторону. Поэтому приложение честно
показывает предупреждение, если формальный критерий по полному градиенту не
достигнут, и возвращает лучшую точку, а не последнюю зашумлённую.

<a id="newton"></a>
## 8. Классический метод Ньютона

**Группа:** методы Ньютона.

**Идея.** Использовать квадратичную модель функции: в текущей точке функция
приближается параболоидом, и следующий шаг делается в минимум этой модели.

**Шаги:**

1. Вычислить градиент `g = ∇f(x)` и матрицу Гессе `H(x)`.
2. Если `‖g‖ ≤ epsilon` — остановиться.
3. Решить систему `H·d = −g` или найти `d = −H⁻¹·g`.
4. Перейти в точку `x_new = x + d` (при необходимости с дробным шагом).
5. Повторять.

**Параметры приложения:** дополнительных параметров нет.

**Особенности.** Вблизи минимума метод сходится очень быстро (квадратично), но
требует обратимости гессиана и хорошей начальной точки. В приложении есть защита:
если гессиан вырожден, используется демпфирование `H + λI`; если направление
Ньютона не является направлением убывания, применяется направление `−g` и
дробный шаг. Если символьный гессиан построить не удалось, используется численный.

<a id="broyden"></a>
## 9. Метод Бройдена

**Группа:** методы Ньютона (квазиньютоновские).

**Идея.** Полный гессиан считать дорого, поэтому метод постепенно строит его
приближение `B` по изменениям градиента. Это квазиньютоновский метод первого
ранга.

**Шаги:**

1. Задать начальное приближение `B = I` (единичная матрица).
2. Вычислить `g = ∇f(x)`.
3. Найти направление `d = −B⁻¹·g`.
4. Сделать шаг с подбором `alpha`.
5. Вычислить новые `x`, `g`, а также `s = x_new − x`, `y = g_new − g`.
6. Обновить приближение `B` по формуле Бройдена.
7. Повторять.

**Параметры приложения:** дополнительных параметров нет.

**Особенности.** Не требует вторых производных, но приближение может стать
плохо обусловленным. В приложении при вырождении матрицы используется
демпфирование, а при направлении не-убывания — сброс к `B = I` и шаг `−g`.

---

<a id="bfgs"></a>
## 10. Метод BFGS

**Группа:** методы Ньютона (квазиньютоновские).

**Идея.** BFGS (Бройден-Флетчер-Гольдфарб-Шанно) — один из самых популярных
квазиньютоновских методов. Вместо полного гессиана он обновляет приближение
обратного гессиана `H` по формуле ранга 2, используя только градиенты.

**Шаги:**

1. Задать начальное приближение `H = I`.
2. Вычислить `g = ∇f(x)`.
3. Найти направление `d = −H·g`.
4. Сделать шаг с подбором `alpha`.
5. Вычислить `s = x_new − x`, `y = g_new − g`.
6. Обновить `H` по формуле BFGS.
7. Повторять.

**Параметры приложения:** дополнительных параметров нет.

**Особенности.** BFGS обычно сходится быстрее Бройдена и устойчивее к ошибкам
округления. В приложении есть защита: если направление не является направлением
убывания, приближение сбрасывается к `I` и используется `−g`.

---

## Краткие рекомендации

- Нет производных или функция негладкая — Хук-Дживс, Нелдер-Мид, овраги,
  покоординатный спуск.
- Нужна высокая точность и функция гладкая — наискорейший спуск, сопряжённые
  градиенты, BFGS.
- Есть хорошая начальная точка и нужна очень быстрая сходимость — классический
  Ньютон.
- Функция — сумма большого числа слагаемых — SGD.

Подробные правила записи функций и градиента смотрите в документе
«Синтаксис» (кнопка в верхней панели).
