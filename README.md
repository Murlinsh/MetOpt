# Optimization Toolkit

Настольное приложение для решения задач оптимизации функций двух переменных.
Пользователь вводит функцию, начальную точку и параметры метода, а программа
показывает готовый ответ или подробное объяснение по итерациям. Все результаты
автоматически сохраняются в папку `results/`.

## Возможности

- Методы без производных: Хук-Дживс, Нелдер-Мид, метод оврагов,
  покоординатный спуск.
- Градиентные методы: наискорейший спуск, сопряжённые градиенты (Флетчер-Ривс), SGD.
- Методы Ньютона: классический Ньютон, Бройден, BFGS.
- Автоматическое построение градиента и матрицы Гессе через SymPy.
- Ручной ввод градиента, если символьное дифференцирование не удалось.
- Два режима: «Готовый ответ» и «Объяснение по итерациям».
- Автосохранение результатов и ошибок в текстовые файлы.
- Запоминание последних введённых данных (`last_input.json`).
- Встроенные документы «Синтаксис» и «Алгоритмы» с крупным шрифтом.

## Установка

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Куда сохраняются результаты

Папка `results/` создаётся автоматически рядом с `main.py`. Имя файла —
дата и время в формате `YYYY-MM-DDTHH-MM-SS.txt`. Полный путь к папке показан
в статусной строке окна, а путь к конкретному файлу — на странице результата.
Кнопка «Папка результатов» в верхней панели открывает эту папку в файловом
менеджере.

## Синтаксис ввода функций

Краткая шпаргалка находится в файле `SYNTAX.md`; её же можно открыть из
приложения кнопкой «Синтаксис» в верхней панели.

Основные правила:

- переменные — только `x` и `y`;
- степень — `**`, а не `^`;
- умножение — явное: `2*x`, а не `2x`;
- функции: `sin, cos, tan, asin, acos, atan, exp, log, sqrt, abs`;
- константы: `pi`, `E`;
- пробелы внутри выражения допускаются.

Пример:

```text
sin(x) + cos(y) + 0.1*(x**2 + y**2)
```

## Документация

В приложении доступны два встроенных документа:

- «Синтаксис» — правила записи функций, градиента и гессиана;
- «Алгоритмы» — подробное объяснение того, как работает каждый метод.

Оба документа открываются из верхней панели. На странице выбора метода есть
кнопка «Как работает метод?»: она открывает документ «Алгоритмы» и переходит
к разделу выбранного метода. Документы отображаются внутри приложения крупным
шрифтом; исходные файлы — `SYNTAX.md` и `ALGORITHMS.md`.

## Тесты

Для запуска тестов установите зависимости разработчика:

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тесты проверяют каждый метод оптимизации, разбор выражений, ручной градиент,
символьные производные и формирование файлов результатов.

## Структура проекта

```text
main.py                 — точка входа
optim_core/             — парсинг, производные, матрицы, численные методы, логи
methods/                — реализации методов и реестр
gui/                    — страницы PyQt6 и главное окно
tests/                  — тесты pytest
SYNTAX.md               — шпаргалка по синтаксису
ALGORITHMS.md           — подробное описание алгоритмов
requirements.txt        — зависимости приложения
requirements-dev.txt    — зависимости для тестов
pytest.ini              — настройки pytest
results/                — результаты расчётов (создаётся автоматически)
```
